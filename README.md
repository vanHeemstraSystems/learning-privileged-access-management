# Learning Privileged Access Management

## Privileged Access Management (PAM)
CISSP Domain: Domain 5 - Identity and Access Management (IAM)

### Learning Objectives:
	•	Understand privileged account risks and controls
	•	Learn PAM solution architectures
	•	Explore just-in-time and zero standing privileges
  
### Study Topics:
	•	Privileged account discovery and inventory
	•	Password vaulting and rotation
	•	Session monitoring and recording
	•	Just-in-time (JIT) access provisioning
	•	Privilege elevation and delegation

### Assignment:
Design a comprehensive PAM strategy for a financial services company. Include privileged account discovery methodology, vault architecture, rotation policies, and monitoring requirements. Create a risk assessment matrix for different types of privileged accounts.
